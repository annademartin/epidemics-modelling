# Epidemic Modelling: Deterministic, Stochastic, and Spatial Dynamics

**Introduction to Computational Science – UvA & VU Amsterdam**

This repository contains the code and reports for two assignments developed for the *Introduction to Computational Science* course at the University of Amsterdam (UvA) and Vrije Universiteit Amsterdam (VU). The projects study epidemic dynamics using compartmental models, progressively increasing model realism and complexity.

Starting from the classic SIR framework, the assignments explore how extensions such as demography, vaccination, seasonality, latent periods, stochasticity, and network structure affect epidemic spreading and system behavior.

---

## Projects Overview

### Project 1 – Deterministic Epidemic Models

* Implemented deterministic ODE-based compartmental models (SIR and extensions).
* Studied the effects of demographic processes, vaccination, and seasonal forcing.
* Analyzed equilibrium behavior, epidemic peaks, and parameter sensitivity.

### Project 2 – Stochastic and Network-Based Models

* Introduced stochastic dynamics to capture randomness in epidemic spread.
* Implemented network-based epidemic models to account for heterogeneous contact structures.
* Compared stochastic outcomes with deterministic predictions.
